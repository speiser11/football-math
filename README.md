# Football Math

A football game for kids where every play is a math problem. Pure static site: open `index.html` or host the folder anywhere.

- `index.html` — the whole game
- `snd/` — stadium sound clips (Mixkit, free license)
- `manifest.json`, `icon-*.png` — lets phones "Add to Home Screen" as an app

Family/friends project. Not affiliated with the NFL.
